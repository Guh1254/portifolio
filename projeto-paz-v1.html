Projeto Paz v1 (Mobile)

MVP: O Início da Jornada (5º Semestre)

Sobre a Versão Inicial

Desenvolvido durante o 5º semestre, esta foi a primeira iteração do Projeto Paz. O objetivo era criar uma solução mobile focada exclusivamente na gestão de vendas para eventos informais. Utilizamos tecnologias consolidadas no mercado web/mobile para validar o MVP (Minimum Viable Product).

Tecnologias Utilizadas (v1)

React Native JavaScript PHP (Backend) MySQL API Rest Docker

O Que Foi Desenvolvido

Nesta etapa, o foco foi entregar funcionalidade rápida para dispositivos móveis:

  • App Mobile: Interface desenvolvida em React Native para Android e iOS.
  • Gestão de Vendas: Funcionalidades básicas de carrinho de compras, cadastro de produtos e registro de vendas.
  • Backend Simples: API REST desenvolvida em PHP para comunicação com o banco de dados MySQL.
  • Autenticação: Sistema de login para vendedores.

🔄 Evolução para KMP

As limitações de escalabilidade e a necessidade de uma versão Desktop/Web desta versão v1 levaram à refatoração completa no 6º semestre, resultando no Projeto Paz 2.0 com Kotlin Multiplatform.

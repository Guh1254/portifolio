Pokédex Simples

Projeto do 1º Semestre

Descrição do Projeto

Este foi um projeto individual desenvolvido para aplicar conceitos fundamentais de desenvolvimento front-end. O objetivo era criar uma interface interativa que consumisse dados de uma API pública, a PokéAPI. A aplicação busca os dados dos Pokémon e os exibe em cards, permitindo que o usuário pesquise por um Pokémon específico em tempo real.

Tecnologias Utilizadas

HTML5 CSS3 JavaScript API REST

Minha Participação no Projeto

Como este foi um projeto individual, fui responsável por todas as etapas do desenvolvimento, desde a concepção da interface até a implementação final. Minhas principais tarefas incluíram:

  • Estruturação (HTML): Criei a estrutura semântica da página, definindo os elementos para a barra de busca, a área de exibição dos cards e o cabeçalho.
  • Estilização (CSS): Desenvolvi todo o layout e a aparência dos cards dos Pokémon, garantindo um design limpo e responsivo.
  • Interatividade (JavaScript): Implementei a lógica para fazer as requisições à PokéAPI usando `fetch`, manipular os dados recebidos (JSON) e renderizar dinamicamente os cards na tela, além de criar a funcionalidade de filtro da barra de busca.

Maratona+

Projeto do 4º Semestre

Descrição do Projeto

O Maratona+ é um aplicativo Android criado para otimizar o processo de inscrição e gerenciamento de maratonas. A plataforma foi desenvolvida para ser simples e intuitiva, permitindo que administradores cadastrem e gerenciem corridas, e que os corredores se inscrevam e acompanhem seu desempenho em tempo real, com funcionalidades como acesso via QR Code e medalhas digitais.

Tecnologias Utilizadas

Java Android (XML) Spring Boot MySQL

Minha Participação no Projeto

No projeto, atuei como Desenvolvedor Front-End (Android). Minha responsabilidade foi construir as telas e a experiência do usuário diretamente no aplicativo, garantindo uma interface funcional e agradável. Minhas principais tarefas foram:

  • Construção de Telas (XML): Desenvolvi os layouts das principais telas do aplicativo, como a lista de maratonas, a tela de inscrição e o perfil do corredor, utilizando XML no Android Studio.
  • Lógica da Interface (Java): Implementei a lógica em Java para conectar os componentes visuais às funcionalidades, como carregar os dados das corridas e processar as inscrições dos usuários.
  • Integração de Funcionalidades: Trabalhei na integração de recursos importantes para a experiência do corredor, como o cronômetro, o histórico de corridas e o sistema de ranqueamento.
  • Conexão com o Back-End: Colaborei com a equipe de back-end para consumir a API REST feita em Spring Boot, garantindo que os dados fossem exibidos corretamente no aplicativo.

Spring Toys

Simulação corporativa de e-commerce com controle transacional de estoque e arquitetura MVC

Descrição do Projeto

O Spring Toys é uma solução full-stack que simula um ambiente e-commerce corporativo completo para uma rede varejista de brinquedos. O sistema conta com um back-end robusto criado em Java 17 com Spring Boot, implementando arquitetura MVC e expondo APIs RESTful para controle transacional de catálogo, estoque, pedidos e usuários com persistência relacional no MySQL via Spring Data JPA.

Tecnologias Utilizadas

Java 17 Spring Boot Spring Data JPA MySQL JavaScript ES6+ HTML5 / CSS3

Atuação Técnica e Integração de Dados

Neste projeto, atuei diretamente na estruturação das camadas de integração entre interface e banco de dados relacional:

  • Consumo e Integração de APIs REST: Implementação de fluxos assíncronos em JavaScript para manipulação dos endpoints do back-end, realizando operações completas de CRUD (produtos, categorias e controle de pedidos).
  • Controle de Estoque e Consistência Transacional: Validação de regras de negócio para evitar divergências e garantir que movimentações de compra reflitam atomicamente na base MySQL.
  • Interface Administrativa: Desenvolvimento dos painéis gerenciais e tabelas operacionais para consulta dinâmica de estoque e gerenciamento de catálogo.

Spring Toys

Projeto do 3º Semestre

Descrição do Projeto

O Spring Toys é um projeto full-stack que simula um e-commerce completo para uma loja de brinquedos. Desenvolvido em equipe, o sistema conta com um back-end robusto criado em Java com Spring Boot, que expõe uma API REST para gerenciar produtos, categorias e usuários. O front-end, construído com HTML, CSS e JavaScript puro, consome essa API para criar uma experiência dinâmica tanto para o cliente quanto para o administrador.

Tecnologias Utilizadas

Java Spring Boot MySQL JavaScript HTML/CSS

Minha Participação no Projeto

Neste projeto, minha principal atuação foi no desenvolvimento front-end e na integração com a API. Fui responsável por traduzir as necessidades do sistema em interfaces funcionais e interativas. Minhas tarefas incluíram:

  • Consumo da API REST: Utilizei JavaScript e a função `fetch` para realizar chamadas (GET, POST, PUT, DELETE) aos endpoints do back-end, buscando e enviando dados de produtos e categorias.
  • Renderização Dinâmica: Criei as funções para popular dinamicamente o catálogo de produtos, os detalhes de cada brinquedo e as listas no painel administrativo com os dados vindos da API.
  • Interface Administrativa: Desenvolvi as telas do painel de administração, incluindo os formulários para criar, editar e excluir brinquedos e categorias, garantindo que todas as interações fossem refletidas no banco de dados através da API.

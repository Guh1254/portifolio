ConnectONGs

Projeto do 2º Semestre

Descrição do Projeto

A plataforma ConnectONGs foi desenvolvida para resolver um desafio crucial: a dificuldade que ONGs enfrentam para encontrar voluntários e gerenciar recursos, e a dificuldade que voluntários têm para encontrar ONGs alinhadas aos seus interesses. O sistema atua como uma ponte, criando um ecossistema centralizado onde ONGs podem divulgar vagas, listar recursos, e voluntários podem se candidatar de forma eficiente.

Tecnologias Utilizadas

PHP MySQL JavaScript Bootstrap HTML/CSS

Minha Participação no Projeto

Neste projeto, atuei na Equipe de Banco de Dados. Minha principal responsabilidade foi a modelagem e estruturação de toda a base de dados que sustentava o sistema. Minhas tarefas incluíram:

  • Modelagem de Dados: Utilizando a ferramenta BrModelo, desenhei o Diagrama Entidade-Relacionamento (DER) para definir as tabelas, seus atributos e os relacionamentos entre elas (ONGs, Voluntários, Vagas, Recursos, etc.).
  • Implementação em MySQL: Fui responsável por traduzir o modelo lógico para o modelo físico, escrevendo o código SQL para criar as tabelas, definir chaves primárias e estrangeiras e garantir a integridade dos dados no MySQL.
  • Colaboração com o Back-End: Trabalhei em conjunto com a equipe de back-end (PHP) para garantir que as consultas ao banco de dados fossem eficientes e que a estrutura criada atendesse a todas as necessidades da aplicação.

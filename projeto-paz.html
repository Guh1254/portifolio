Projeto Paz 2.0 (KMP)

Evolução da Arquitetura: Sistema Multiplataforma com IoT

Evolução do Projeto

No 6º semestre, o Projeto Paz passou por uma reformulação total. Abandonamos a arquitetura monolítica mobile anterior (React Native) para adotar Kotlin Multiplatform (KMP). O objetivo foi validar a capacidade de compartilhar código de negócio entre plataformas nativas (Android, iOS, Web e Desktop) mantendo a performance nativa.

Stack Tecnológico Avançado

Kotlin Multiplatform (KMP) Compose Multiplatform Spring Boot 3 Spring Security (JWT) MySQL AWS S3 IoT (ESP32/MQTT)

Minha Participação e Arquitetura

Como Desenvolvedor Full-Stack e Arquiteto de Software, minhas principais responsabilidades nesta nova versão foram:

  • Arquitetura KMP: Implementação do compartilhamento de código (Networking, ViewModels, Modelos) entre 4 plataformas, reduzindo duplicidade em 40%.
  • Back-End Robusto: Migração do antigo back-end para Spring Boot, com segurança JWT, Swagger e integração com AWS S3 para imagens.
  • Interface Unificada: Uso de Compose Multiplatform para criar interfaces responsivas que se adaptam a telas mobile e desktop com a mesma base de código.
  • Integração IoT: Configuração de sensores ESP32 comunicando via MQTT para monitoramento ambiental em tempo real.

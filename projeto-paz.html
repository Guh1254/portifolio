Projeto Paz

Projeto do 5º Semestre

Descrição do Projeto

O Projeto Paz é um aplicativo mobile responsivo, desenvolvido em React Native, com o objetivo de digitalizar e otimizar a gestão de vendas informais em eventos religiosos. A plataforma automatiza o registro de vendas, o controle de estoque e a geração de relatórios, substituindo métodos manuais propensos a erros e profissionalizando a atividade dos vendedores.

Tecnologias Utilizadas

React Native PHP MySQL JWT Docker AWS S3

Minha Participação no Projeto

Neste projeto, integrei a equipe de Front-End, com foco total no desenvolvimento do aplicativo mobile. Minha principal responsabilidade foi a criação das interfaces e da lógica de interação do usuário utilizando React Native. Minhas tarefas incluíram:

  • Desenvolvimento de Telas: Construí as principais telas do aplicativo, como a de login de vendedor, registro de vendas, cadastro de produtos e visualização de estoque.
  • Criação de Componentes: Desenvolvi componentes reutilizáveis em React Native para garantir a consistência visual e a manutenibilidade do código.
  • Integração com a API: Fui responsável por conectar o aplicativo com o back-end (PHP), implementando as chamadas para registrar vendas, buscar produtos e atualizar o estoque em tempo real.
  • Autenticação de Usuário: Implementei o fluxo de autenticação via Token JWT, garantindo que apenas vendedores autorizados tivessem acesso às funcionalidades de gerenciamento.

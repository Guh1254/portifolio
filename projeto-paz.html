Projeto PAZ

IoT, Cloud & Telemetria de Dados Operacionais e Ambientais

Visão Geral da Plataforma

O Projeto PAZ é uma plataforma robusta desenvolvida para validação de arquiteturas modernas em escala real, com foco em ingestão de dados de telemetria contínua, processamento em nuvem e distribuição de informações. O projeto alcançou reconhecimento acadêmico com Publicação Científica no 8º EnGeTec (Encontro de Gestão e Tecnologia).

A arquitetura integra microcontroladores IoT (ESP32) conectados via Wi-Fi/MQTT para monitoramento e coleta contínua de telemetria, alimentando um backend em Spring Boot 3 na nuvem com persistência de dados estruturados em MySQL e armazenamento de objetos no AWS S3.

Stack Tecnológico Avançado

Kotlin Multiplatform (KMP) Compose Multiplatform Spring Boot 3 MySQL AWS S3 ESP32 (IoT / MQTT) Docker

Arquitetura & Pipeline de Dados

Como desenvolvedor e arquiteto de dados/software do ecossistema, minhas responsabilidades envolveram:

  • Ingestão e Pipeline de Telemetria: Configuração e comunicação de sensores via hardware ESP32, garantindo envio resiliente de dados operacionais e de telemetria via MQTT/HTTP.
  • Arquitetura Multiplataforma: Compartilhamento de regras de negócio, serialização e chamadas de rede entre Android, iOS, Desktop e Web via Kotlin Multiplatform.
  • Backend & Persistência em Nuvem: Desenvolvimento de API REST com Spring Boot 3, autenticação segura com JWT e integração de armazenamento de mídia com buckets AWS S3.
  • Containers & Deploy: Empacotamento de serviços com Docker para garantia de portabilidade e facilidade de sustentação.
